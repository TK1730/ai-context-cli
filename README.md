# AIコンテキスト抽出CLIツール 基本設計書

## 1. 概要
指定したプロジェクトディレクトリ内のソースコードやディレクトリ構造を高速に解析し、LLM（大規模言語モデル）やAIエディタに読み込ませるためのコンテキスト（要約マークダウン）を自動生成するCLIツール。

## 2. 目的
- 複数ファイルにまたがるコードやディレクトリ構成を1つのテキストにまとめ、AIへのプロンプト入力を効率化する。
- 関連しないファイル（ビルド成果物やパッケージ群）を自動で除外し、AIの読み込みトークンを節約しつつハルシネーションを防ぐ。

## 3. インターフェース設計（CLI引数）
コマンドラインから以下のフラグを受け取る。

| フラグ | デフォルト値 | 説明 |
| :--- | :--- | :--- |
| `-dir` | `.` (カレント) | 解析対象のルートディレクトリ |
| `-out` | `context.md` | 出力先のファイル名（※未実装、今後追加予定） |

## 4. モジュール構成
処理の責任を分離し、保守性とテスト容易性を高めるため、以下の3グループに分割して実装する。

### 4.1. main.go (司令塔)
- `flag` パッケージを用いたコマンドライン引数の解析
- 各モジュール（Scanner, Generator, Writer）の呼び出しと全体フローの制御
- エラーハンドリングとユーザーへのターミナル出力

### 4.2. scanner.go (探索・抽出 / Group 1)
- **役割**: 指定ディレクトリを再帰的に探索し、処理対象となるファイルのパス一覧を生成する。
- **除外ルール**: 以下のディレクトリは探索から除外（`filepath.SkipDir`）し、処理を高速化する。
  - `.git`
  - `node_modules`
  - `.next`
  - `.venv`
- **主要関数**: `ListFiles(rootDir string) ([]string, error)`

### 4.3. generator.go (生成・結合 / Group 2) ※今後実装
- **役割**: ファイルパスの一覧を受け取り、LLM向けのマークダウン文字列を構築する。
- **処理内容**:
  1. プロジェクトの全体像を示すツリー構造テキストの生成
  2. 対象ファイルの中身の読み込み
  3. 「ファイルパス ＋ コードブロック」の形式での結合
- **主要関数**: `GenerateMarkdown(targetDir string, files []string) (string, error)`

### 4.4. writer.go (出力 / Group 3) ※今後実装
- **役割**: 生成された文字列を指定されたパスにファイルとして保存する。
- **主要関数**: `SaveToFile(content string, outputPath string) error`
